# FILMFRAME 135

一个在浏览器本地运行的 135 胶片画框编辑器。上传照片后可选择四种胶片结构，调整构图，并为每张照片分别编辑胶卷型号、片边编号、卷号、地点和日期。

## 特点

- 原图只做裁切、缩放、位移和 90° 旋转，不添加 AI 重绘或滤镜
- 每张照片独立保存模板和片边信息
- 20 种常见 135 胶卷型号，片边编号仍可手动修改
- 单张导出 PNG，多张打包导出 ZIP
- 照片与编辑状态仅保留在当前浏览器内存中

## 本地运行

```bash
npm install
npm run dev
```

## 构建与验证

```bash
npm run build
npm run test:sites
```
